# CareerCoach AI

AI-powered career coaching application.

## Quick start

See [backend/README.md](backend/README.md) for setup, configuration, and running the app.

```bash
cd backend
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
python app.py
```

## Structure

```
backend/     Flask app, templates, tests, CI config
.github/     GitHub Actions workflow
```
